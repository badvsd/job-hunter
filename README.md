# 🕊 «Джонатан Ливингстон» — твой помощник в поиске работы

Это программа, которая **ищет вакансии за тебя** и **защищает от мошенников**.

Представь: тебе нужна работа. Ты заходишь на сайты вакансий и вручную листаешь
сотни объявлений, пишешь письма, боишься нарваться на обман. «Джонатан» делает
это сам: собирает вакансии со всех площадок сразу, проверяет каждого работодателя
«на честность» и готовит для тебя резюме и письма.

> 💡 **Слова, которые встречаются впервые, объясняются в [Словарике](#словарик-терминов)
> в самом низу этой страницы.** Нажми на слово — и попадёшь к объяснению.

---

## Что он умеет

1. **🔎 Ищет работу на многих площадках сразу.** Это HH.ru, государственная база
   «Работа России», Telegram-каналы с вакансиями, Авито, ВКонтакте, Одноклассники,
   Habr Career, SuperJob, LinkedIn, Instagram, а ещё зарубежные — Reddit, Bluesky,
   Mastodon, Hacker News, RemoteOK и другие. Всего **17 соцсетей + 2 главные базы**.

2. **🛡 Проверяет работодателя (антифрод).** Перед откликом программа смотрит:
   настоящий ли у компании [ИНН](#словарик-терминов), не «однодневка» ли это,
   нет ли у неё долгов и судов, и не похоже ли объявление на одну из 15+ известных
   схем обмана (дроппинг, «оформи карту», «оплати обучение» и т.д.). Итог — оценка
   доверия от 0 до 100 % и понятные ссылки на государственные реестры.

3. **📄 Подгоняет резюме под вакансию.** Берёт твоё резюме и переделывает его так,
   чтобы оно понравилось «роботу», который отбирает резюме (это называют [ATS](#словарик-терминов)).
   Умеет делать 5 разных вариантов резюме и выбирать лучший под конкретную вакансию.

4. **✉️ Пишет сопроводительные письма.** В трёх стилях: деловой, живой и короткий
   (для Telegram, ВКонтакте и Авито).

5. **🤖 Автопилот откликов.** Может сам нажать кнопку «Откликнуться» на HH.ru
   (подробнее — в разделе про [автопилот](#-автопилот-откликов-playwright)).

## Из чего состоит программа

```
job-hunter-bots/
├── webapp/server.py            ← главный файл: сайт + API (его запускают)
├── webapp/static/index.html    ← красивая страничка, которую видит человек
├── shared_engine/              ← «мозг»: поиск, антифрод, резюме, письма
│   ├── engine.py
│   ├── social_search.py
│   └── miniapp.py
├── variant_a_personal/         ← Вариант А: личный бот «для себя» (без лимитов)
│   └── bot_personal.py
├── variant_b_saas/             ← Вариант Б: платный сервис с тарифами (на продажу)
│   └── bot_saas.py
├── worker/autoapply.py         ← автопилот откликов (Playwright)
├── test_smoke.py               ← самопроверка: нажимает все кнопки изнутри
├── requirements.txt            ← список библиотек, которые нужны программе
├── railway.json                ← настройки для хостинга Railway
└── .env.example                ← образец настроек (токены, ключи)
```

Программа написана на языке **Python**. Библиотеки (готовые «кубики» кода) —
это [FastAPI](#словарик-терминов) (сайт), [aiogram](#словарик-терминов) (Telegram-бот)
и другие. Все они перечислены в файле `requirements.txt`.

## Как запустить у себя на компьютере

Тебе нужен установленный **Python** (версия 3.10 или новее).
Скачать можно бесплатно с [python.org](https://www.python.org/downloads/).

### Шаг 1. Установи библиотеки

Открой командную строку (на Windows — «Командная строка» или PowerShell,
на Mac/Linux — «Терминал»), перейди в папку проекта и выполни:

```bash
pip install -r requirements.txt
```

### Шаг 2. Запусти сайт

```bash
python webapp/server.py
```

Если всё хорошо, в консоли появится надпись со ссылкой. Открой в браузере:

```
http://localhost:8085
```

> На Windows, если команда `python` не работает, попробуй `py` или полный путь
> к Python, например `C:\Python311\python.exe webapp/server.py`.

### Шаг 3. Проверь, что всё в порядке

В отдельном окне запусти самопроверку:

```bash
python test_smoke.py
```

Она проверит поиск, антифрод, резюме, письма и базы данных. Если в конце ты видишь
**«✅ ВСЕ МОДУЛИ УСПЕШНО ПРОШЛИ ПРОВЕРКУ!»** — всё работает.

## Как запустить Telegram-ботов

Есть два бота:

* **Вариант А (личный)** — без лимитов и оплаты, «для себя»:
  ```bash
  python variant_a_personal/bot_personal.py
  ```
* **Вариант Б (сервис)** — с тарифами, квотами и админкой, «на продажу»:
  ```bash
  python variant_b_saas/bot_saas.py
  ```

Перед запуском нужно положить **токен бота** в переменную окружения.
[Токен](#словарик-терминов) выдаёт `@BotFather` в Telegram, когда ты создаёшь бота.

На Windows (PowerShell):
```powershell
$env:PERSONAL_BOT_TOKEN="1234567890:ТВОЙ_ТОКЕН_ОТ_BOTFATHER"
python variant_a_personal/bot_personal.py
```

На Mac/Linux:
```bash
export PERSONAL_BOT_TOKEN="1234567890:ТВОЙ_ТОКЕН_ОТ_BOTFATHER"
python variant_a_personal/bot_personal.py
```

Подробный список всех настроек — в файле [`.env.example`](.env.example).

## 🚀 Как выложить в интернет на Railway

[Railway](https://railway.app) — это **хостинг**: место в интернете, где твоя
программа работает круглосуточно, даже когда твой компьютер выключен. На старте
есть бесплатный лимит, дальше — от пары долларов в месяц.

### Что уже готово (я подготовил)

* `requirements.txt` — Railway сам установит все библиотеки.
* `railway.json` — Railway сам поймёт, какую команду запускать.
* Программа теперь открывает порт правильно (`0.0.0.0`) — это обязательное
  условие, чтобы сайт был виден снаружи.

### Пошаговая инструкция

1. **Создай аккаунт** на [railway.app](https://railway.app) (можно войти через GitHub).

2. **Залей код.** Самый простой способ — через GitHub:
   * Создай на GitHub репозиторий и залей туда эту папку (или подключи проект
     прямо через интерфейс Railway «Deploy from GitHub»).
   * В Railway нажми **New Project → Deploy from GitHub repo** и выбери свой репозиторий.

3. **Railway сам соберёт проект.** Он увидит `requirements.txt` и `railway.json`
   и сделает всё автоматически (это делает «строитель» под названием
   [Nixpacks](#словарик-терминов)).

4. **Добавь настройки (переменные окружения).** В Railway открой свой сервис →
   вкладка **Variables** → добавь то, что тебе нужно. Для старта хватит одной:
   | Имя | Значение | Зачем |
   |---|---|---|
   | `PERSONAL_BOT_TOKEN` | твой токен от BotFather | чтобы работал Telegram-бот |

   Для Telegram Mini App добавь также `WEBAPP_URL` — это адрес твоего сайта вида
   `https://твой-сервис.up.railway.app`.

5. **Открой сайт.** Railway даст адрес вида `https://твой-сервис.up.railway.app`.
   Открой его в браузере — это и есть твоё приложение в интернете.

6. **(Необязательно) Подключи свой домен.** Во вкладке **Settings → Networking →
   Custom Domain** можно привязать своё имя сайта.

### ⚠️ Важно знать про Railway

* **Порт задаётся автоматически.** Railway сам кладёт в переменную `PORT` нужный
  номер. Наша программа его читает, поэтому ничего настраивать не нужно.

* **Данные (SQLite) стираются при перезапуске.** Базы данных лежат в файлах
  рядом с кодом, а Railway при каждом обновлении создаёт чистую копию. Это значит:
  профили и тарифы пользователей сбросятся. Чтобы данные жили вечно, подключи
  в Railway **Volume** (диск) и направь туда файлы баз — либо переходи на
  настоящую базу данных (PostgreSQL). Для первого запуска и теста это не критично.

* **Автопилот откликов на Railway не работает.** Ему нужен настоящий браузер
  Chrome, которого на Railway нет. Всё остальное (поиск, антифрод, резюме, письма,
  сайт, бот) работает полностью. Автопилот — только на своём компьютере.

## 🤖 Автопилот откликов (Playwright)

Это функция, которая **сама нажимает кнопку «Откликнуться»** на HH.ru в настоящем
браузере. Она честная: не обходит капчу и не взламывает защиту.

* **HH.ru** — отклик автоматизирован полностью.
* **Авито, ВК, ОК, LinkedIn, Instagram, Telegram** — там нужна капча или живой
  вход, поэтому программа просто готовит письмо и просит нажать кнопку самому.

**Чтобы это работало**, нужен установленный браузер Chrome и библиотека Playwright.
По умолчанию отклик идёт в режиме «черновик» (ничего не отправляется), пока ты
явно не разрешишь отправку — так безопаснее.

> Автопилот — необязательная часть. Сайт, поиск, антифрод и резюме работают и без него.

## 🔑 Все настройки (переменные окружения)

Полный список с пояснениями лежит в файле [`.env.example`](.env.example). Главные:

| Переменная | Что делает |
|---|---|
| `PERSONAL_BOT_TOKEN` | токен личного бота (Вариант А) |
| `SAAS_BOT_TOKEN` | токен коммерческого бота (Вариант Б) |
| `BOT_USERNAME` | имя бота для кнопок-ссылок |
| `WEBAPP_URL` | публичный адрес сайта (нужен для Telegram Mini App) |
| `OPENAI_API_KEY` / `GEMINI_API_KEY` / `GROQ_API_KEY` | ключи ИИ (не обязательны) |
| `BSKY_HANDLE` + `BSKY_APP_PASSWORD` | для живого поиска в Bluesky |
| `APPLY_DRY_RUN` | `1` = черновик, `0` = отправлять по-настоящему |
| `PORT` / `HOST` | порт и адрес (обычно не трогают) |

**Без единой настройки** программа тоже работает: сайт откроется, поиск и антифрод
будут работать. Не будет только входа через Telegram и бота.

## Словарик терминов

**API** — «дверь», через которую одна программа общается с другой. Наш сайт отдаёт
данные боту через API.

**aiogram** — библиотека Python для создания Telegram-ботов.

**ATS** (Applicant Tracking System) — программа-робот, которой компании отсеивают
резюме. Ищет в резюме нужные слова. Наша программа умеет подгонять резюме под ATS.

**FastAPI** — библиотека Python, на которой сделан наш сайт и API.

**Хостинг** — место в интернете, где программа работает постоянно (например, Railway).

**ИНН** — индивидуальный номер налогоплательщика. У каждой настоящей компании он есть.
Проверив ИНН по алгоритму, можно понять, настоящая ли компания.

**LLM / ИИ** — «умный текстовик» (искусственный интеллект), который пишет письма
и адаптирует резюме. Наша программа умеет работать даже с бесплатным встроенным ИИ.

**Nixpacks** — автоматический «строитель» на Railway. Он читает `requirements.txt`
и сам собирает программу.

**Playwright** — библиотека, которая управляет настоящим браузером (как робот-человек
кликает по странице).

**SQLite** — простая база данных, которая хранится в одном файле. Используется
для профилей и тарифов.

**Токен** — секретный «пароль-ключ», который выдаёт BotFather. По нему программа
понимает, каким ботом управлять.

**Telegram Mini App** — мини-приложение, которое открывается прямо внутри Telegram.

**ЕГРЮЛ / ФССП / КАД** — государственные открытые реестры: список компаний (ЕГРЮЛ),
список долгов (ФССП — судебные приставы) и судебные дела (КАД — картотека арбитражных дел).
По ним программа проверяет, честный ли работодатель.

**Дроппинг** — мошенническая схема: человека просят оформить на себя банковскую карту
или сим-карту и передать её другим. Это незаконно и опасно.

**Trust Score** — «оценка доверия» от 0 до 100 %, которую программа ставит работодателю.

**Эндпоинт** — конкретный адрес (URL), по которому сайт отдаёт данные. Например,
`/api/search` — адрес, по которому приходит список вакансий.
